## 说明

- 每个包在上传前都做过 CRC 完整性校验、包信息读取与签名验证，`sha256` 值写在各 Release 页面。
- 安装前需在系统设置里允许“安装未知应用”；若提示解析失败，多半是系统版本过低或 CPU 架构不匹配。
- 所有安装包均为原样搬运，未做任何修改。
